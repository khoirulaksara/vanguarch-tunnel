Expose your local servers to the world with unparalleled elegance

Vanguarch is a fast, predictable, and gorgeous desktop GUI wrapper for cloudflared. Expose ports, inspect webhooks, and monitor analytics with zero CLI headache.

Download MSI Installer Download Portable (.exe)

Visualizing Dashboard & Web Inspector

Vanguarch includes a fully integrated dark-cyberpunk styled dashboard, Recharts-based statistics, and an ngrok-like proxy request capture log.

Everything you need for local tunneling

Packed with developer-first utilities that make tunneling smooth, reliable, and observable.

1-Click Control

Start, stop, and restart tunnels instantly. Presets let you save configurations for different microservices and load them with one click.

Detailed Analytics

Keep track of HTTP request logs, success/error distributions, bandwidth rates, and top endpoints with real-time interactive charts.

Smart Health Alerts

Get system tray alerts and OS notifications whenever a tunnel connects, goes offline, or recovers from outages. Background checks auto-monitor status.

Projects Auto-Discovery

Let Vanguarch scan your workspace directories and automatically discover local framework servers (Vite, WordPress, Laravel, Next.js).

Quick Share Server

Need to share a static folder or directory? Boot up Vanguarch's integrated file sharing web server and share files over a tunnel in seconds.

Robust Process Health

Built-in process watchdog kills orphaned `cloudflared` instances using system-level calls (WMIC/pkill) to avoid silent port conflicts.

Ngrok-style Inspector

Intercept & Replay Webhooks in Real-time

Enable the **Web Inspector Proxy** to capture incoming HTTP requests. Drill down into query parameters, body payloads, and headers for both request and response.

  • 1-Click Replay: Resend requests to local backend to test fixes.
  • Edit & Replay: Modify paths, headers, and request body before replay.
  • Auto JSON formatting and copy widgets.
